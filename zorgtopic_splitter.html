ZORGTOPICS
Hoe werkt deze tool?
Elk kwartaal:
  1. Upload de klinimetrie-exports (lage rug, nek, schouder) hieronder
  2. Upload de declaratie-exports (lage rug, nek, schouder) hieronder
  3. Klik op Verwerken
  4. Download de bestanden per therapeut, los of als zip
Wat de tool doet:
  • Herkent automatisch het zorggebied (lage rug / nek / schouder) op basis van de bestandsnaam
  • Splitst per therapeut op in een eigen Excel-bestand
  • Kleurt cellen automatisch rood: bij klinimetrie als de waarde X is; bij declaraties als er bij DOC eerste behandeling een startcode staat én F-Code = SBST "nee" is
  • Tabbladvolgorde: Klinimetrie lage rug → Declaratie lage rug → Klinimetrie nekpijn → Declaratie nekpijn → Klinimetrie schouderpijn → Declaratie schouderpijn

Alles gebeurt lokaal in je browser — er wordt niets naar een server verstuurd.
